# OOP Basic Assignments

Simple introductory Object-Oriented Programming tasks covering core concepts: Encapsulation, Inheritance, Polymorphism, and Abstraction.

## Assignments

### Task 1: Bank Account
* **Concept:** Encapsulation
* **Description:** Create a `BankAccount` class with private balance variables.
* **Requirements:**
  - Private attributes: `_account_number`, `_balance`
  - Methods: `deposit(amount)`, `withdraw(amount)`, `get_balance()`

### Task 2: Animal Sounds
* **Concept:** Inheritance
* **Description:** Create a base class `Animal` and child classes for specific animals.
* **Requirements:**
  - Base class `Animal` with attributes `name` and `age`.
  - Child classes: `Dog` and `Cat`.
  - Override the `make_sound()` method in each class.

### Task 3: Geometric Shapes
* **Concept:** Abstraction & Polymorphism
* **Description:** Create an abstract `Shape` class and implement concrete shapes.
* **Requirements:**
  - Abstract class `Shape` with methods `area()` and `perimeter()`.
  - Derived classes: `Rectangle` and `Circle`.
  - Calculate area and perimeter for different shape instances in a loop.

### Task 4: Library
* **Concept:** Class Interaction
* **Description:** Create a simple system where a `Library` contains multiple `Book` objects.
* **Requirements:**
  - `Book` class with `title`, `author`, `is_borrowed`.
  - `Library` class with a list of books.
  - Methods: `add_book()`, `borrow_book()`, `show_books()`.
